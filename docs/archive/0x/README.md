# 0.x documentation (archived)

These are the hand-maintained manuals for WPToolkit 0.x, kept for anyone still on a 0.x tag. They
describe APIs that no longer exist in 1.0 (`Registry`, `Model`, `Utils\*`).

For 1.0, start at the [README](../../../README.md) and the [guides](../../guides/). Moving a 0.x
plugin or theme: [migrating from 0.x](../../guides/migrating-from-0x.md).
